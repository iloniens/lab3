## Лабораторна робота №3. Маніпуляція даними та комплексні запити

SQL-запити DML (INSERT, UPDATE, DELETE) та DQL (фільтрація, сортування, агрегація, JOIN, підзапити, UNION), виконані в DBeaver на базі даних з лабораторної роботи №2.

Директорія з файлами: 

Файли:
- `task_1_insert.sql` – INSERT: новий користувач і товар
- `task_2_update.sql` – UPDATE: зміна ціни товару
- `task_3_delete.sql` – DELETE: видалення позиції замовлення
- `task_4_where_and.sql` – WHERE + AND
- `task_5_where_in.sql` – WHERE + IN
- `task_6_where_like.sql` – WHERE + LIKE
- `task_7_order_by.sql` – ORDER BY
- `task_8_count.sql` – COUNT + GROUP BY
- `task_9_sum.sql` – SUM
- `task_10_avg_min_max.sql` – AVG, MIN, MAX
- `task_11_group_by_join.sql` – GROUP BY + JOIN
- `task_12_having.sql` – HAVING
- `task_13_inner_join.sql` – INNER JOIN (4 таблиці)
- `task_14_left_join.sql` – LEFT JOIN
- `task_15_subquery.sql` – підзапит
- `task_16_union.sql` – UNION
